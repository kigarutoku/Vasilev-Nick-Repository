Далее опишу основные команды git, как ими пользоваться, и напишу пример использования



1. git init

Команда git init используется для создания локального Git-репозитория. Она инициализирует систему контроля версий в текущей директории.



Пример использования:

mkdir my-project

cd my-project

git init



В результате в папке проекта создаётся скрытая директория .git, в которой хранится история изменений и служебная информация Git.



2\. git clone

Команда git clone используется для копирования существующего удалённого репозитория на локальный компьютер.



Пример использования:

git clone https://github.com/kigarutoku/Vasilev-Nick-Repository.git



В результате создаётся локальная копия репозитория, содержащая файлы проекта и его историю коммитов.



3\. git add

Команда git add добавляет изменения в индекс Git. Индекс используется для подготовки файлов к последующему коммиту.



Пример использования:

git add README.md



После выполнения команды файл будет подготовлен к коммиту, но сами изменения ещё не сохранены в истории репозитория.



4\. git commit

Команда git commit сохраняет подготовленные изменения в локальной истории репозитория.



Пример использования:

git add README.md

git commit -m "Добавлена информация обо мне"



В результате создаётся новый коммит с уникальным идентификатором и сообщением, описывающим внесённые изменения.



5\. git push

Команда git push отправляет локальные коммиты в удалённый репозиторий, например на GitHub.



Пример использования:

git push -u origin git-commands



В результате локальные коммиты становятся доступными в удалённом репозитории.



6\. git pull

Команда git pull получает изменения из удалённого репозитория и интегрирует их в текущую локальную ветку.



Пример использования:

git pull origin main



Команда получает актуальные изменения из ветки main удалённого репозитория и объединяет их с текущей локальной веткой. Если изменения будут конфликтовать в локальными, Git может потребовать разрешить конфликт вручную.



Вывод:

Git является системой контроля версий, позволяющей отслеживать изменения файлов, сохранять историю разработки и организовывать совместную работу над проектами.
